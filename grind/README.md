# 16 Недель - Персональный План Развития

Статический одностраничный веб-приложение (SPA) для отслеживания личного прогресса по 16-недельному плану обучения, тренировок и развития навыков.

## 🚀 Быстрый старт

1. Скачайте все файлы проекта
2. Откройте файл `index.html` в любом современном браузере
3. Всё готово! Приложение работает полностью локально, без сервера

## 📁 Структура проекта

```
16week-plan-app/
├── index.html          # Главная HTML страница
├── styles.css          # Все стили приложения
├── app.js              # Вся логика приложения (включая план)
└── README.md           # Этот файл
```

## ✨ Возможности

### 📅 План 16 недель (Read-Only)
- Жёстко захардкоженный детальный план на 16 недель
- Разворачиваемая структура: недели → дни → блоки → задачи
- План **только для чтения** — изменения не сохраняются
- Используется как базовая структура для вашего развития

### 📝 Notes (Заметки)
- Создание личных заметок с заголовком и содержанием
- Сохранение в localStorage браузера
- Удаление ненужных заметок
- Экспорт/импорт в JSON

### 🍅 Pomodoro Timer
- Настраиваемые интервалы работы и перерыва (по умолчанию 25/5 минут)
- Таймер с визуальным отображением
- Возможность добавить заметку к каждой сессии
- История всех сессий с датами
- Экспорт/импорт истории

### 💪 Training Log (Журнал тренировок)
- Запись тренировок с типом (A/B/C)
- Детальные заметки об упражнениях, повторах, самочувствии
- История всех тренировок
- Экспорт/импорт данных

### 🎯 CF-tracker (Трекер задач Codeforces)
- Отслеживание решённых задач
- Уровень сложности (easy/medium/hard)
- Статус (решена/попытка/разбор)
- Заметки о подходе к решению
- Экспорт/импорт данных

### 📊 Dashboard
- Обзор текущего прогресса
- Счётчики всех активностей
- Индикатор прогресса по неделям

## 🔒 Приватность и Безопасность

- **Все данные хранятся только в вашем браузере** (localStorage)
- **Никаких сетевых запросов** — приложение работает полностью офлайн
- **Никакой отправки данных** в интернет
- Данные сохраняются только на вашем устройстве

```json
{
  "exportDate": "2025-02-08T10:30:00.000Z",
  "notes": [
    {
      "id": 1707392400000,
      "title": "Заголовок заметки",
      "content": "Содержание заметки",
      "date": "2025-02-08T10:30:00.000Z"
    }
  ],
  "trainingLog": [
    {
      "id": 1707392400001,
      "date": "2025-02-08",
      "type": "A",
      "notes": "Приседания 3х10, отжимания 3х15",
      "createdAt": "2025-02-08T10:30:00.000Z"
    }
  ],
  "cfTracker": [
    {
      "id": 1707392400002,
      "date": "2025-02-08",
      "problem": "800A",
      "difficulty": "easy",
      "status": "solved",
      "notes": "Решил за 15 минут",
      "createdAt": "2025-02-08T10:30:00.000Z"
    }
  ],
  "pomodoroHistory": [
    {
      "id": 1707392400003,
      "date": "2025-02-08T10:30:00.000Z",
      "duration": 25,
      "note": "Математика: квадратные уравнения"
    }
  ],
  "currentWeek": 1
}
```

### Как экспортировать данные

1. Перейдите в раздел "Экспорт/Импорт"
2. Нажмите кнопку "📤 Экспорт JSON"
3. Файл автоматически скачается с именем вида: `16weeks-data-2025-02-08.json`

### Как импортировать данные

1. Перейдите в раздел "Экспорт/Импорт"
2. Нажмите кнопку "📥 Импорт JSON"
3. Выберите ранее экспортированный JSON файл
4. Подтвердите импорт (это перезапишет текущие данные)

**⚠️ Важно:** План 16 недель не экспортируется и не импортируется — он всегда доступен в приложении как жёстко закодированная структура.

## 🎨 Использование

### Работа с планом
1. Откройте раздел "План 16 недель"
2. Нажмите на заголовок недели, чтобы развернуть её
3. Просмотрите дни и задачи
4. Используйте план как ориентир для своих активностей

### Добавление заметок
1. Откройте раздел "Notes"
2. Введите заголовок и содержание
3. Нажмите "Добавить заметку"
4. Заметка автоматически сохранится

### Использование Pomodoro
1. Откройте раздел "Pomodoro"
2. Настройте время работы и перерыва (если нужно)
3. Нажмите "Start" для начала сессии
4. После завершения добавьте заметку о том, чем занимались
5. Сессия автоматически добавится в историю

### Запись тренировок
1. Откройте раздел "Training Log"
2. Выберите дату и тип тренировки (A/B/C)
3. Опишите выполненные упражнения и повторы
4. Нажмите "Добавить запись"

### Отслеживание CF задач
1. Откройте раздел "CF-tracker"
2. Введите номер задачи (например, 800A)
3. Выберите сложность и статус
4. Добавьте заметки о решении (опционально)
5. Нажмите "Добавить задачу"

## 🔄 Резервное копирование

Рекомендуется регулярно экспортировать данные:
- Еженедельно делайте экспорт для безопасности
- Храните файлы экспорта в облачном хранилище (Google Drive, Dropbox)
- Перед очисткой кеша браузера делайте экспорт

## ⚠️ Важные замечания

1. **Очистка данных браузера** — если вы очистите localStorage браузера, все личные данные будут удалены (план 16 недель останется, так как он в коде)
2. **Приватный режим браузера** — в приватном режиме данные не сохраняются между сессиями
3. **Разные браузеры** — данные не синхронизируются между разными браузерами
4. **План нельзя изменить** — это сделано специально, чтобы план оставался эталоном

## 🎯 Рекомендации по использованию

1. **Регулярно обновляйте Dashboard** — отмечайте текущую неделю
2. **Делайте заметки после каждой Pomodoro сессии** — это поможет отслеживать, на что уходит время
3. **Записывайте тренировки сразу** — пока помните количество повторов
4. **Анализируйте CF-tracker** — смотрите, какие типы задач даются легче/сложнее
5. **Еженедельный экспорт** — создавайте резервные копии
